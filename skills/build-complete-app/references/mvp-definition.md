# Verified Web MVP

An MVP is complete only when:

- the primary persona can finish the primary journey using real UI;
- core behavior is implemented end to end;
- loading, empty, success, validation, and recoverable error states exist where relevant;
- automated tests cover the core behavior;
- a production build succeeds;
- the rendered app is inspected at desktop and mobile target viewports;
- no body scroll, overlap, missing content, unreadable text, or unusable target blocks the journey;
- setup and start instructions work;
- known limitations are recorded;
- `progress-verifier` verifies the observable acceptance criteria.

Mocks are acceptable only when the contract identifies them and they do not fake the core promised outcome.
