# Reminder Escalator

1. Read due dates, priority, dependency impact, last reminder, and current evidence.
2. Do not remind before the due threshold unless a new blocker makes action urgent.
3. Combine non-urgent items into one digest.
4. Send an immediate reminder only for material blockers or imminent loss.
5. State what is needed, why now, required effort, and impact of continued delay.
6. Increase escalation gradually: digest, direct reminder, explicit blocker, then request a scope or ownership decision.
7. Never use guilt, streaks, artificial urgency, or repeated unchanged messages.
8. Record reminder time and outcome in the ledger.

If nothing requires human attention, report nothing.
