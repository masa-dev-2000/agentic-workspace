# Stack routing

Preserve an existing viable stack. For a new project use React + TypeScript + Vite + npm.

Add Supabase only for a real need involving persisted shared data, authentication, storage, realtime, queues, vectors, or database policy. Use the Supabase Skill whenever Supabase is involved.

Keep secrets off the client. A requirement for privileged credentials, third-party secret keys, webhooks, scheduled jobs, or trusted business logic implies a server-side boundary.

Prefer audited local catalog packages for repeated technical capabilities. Otherwise prefer maintained public libraries with compatible licenses and small dependency cost. Implement locally when the capability is product-specific or the dependency costs more than it saves.
