講習の進捗状況を確認する。全講習の一覧、または特定講習の詳細を表示。

引数: [講習名] - 省略時は全講習の一覧を表示
例:
  /training-status
  /training-status "AI基礎講座"

## 手順

### パターン A: 全講習一覧（引数なし）

1. カレントディレクトリの `.training/` 配下を走査
2. 各サブディレクトリ（= 各講習）のファイル存在状況をチェック
3. 以下の形式で表示:

```
## 講習一覧

| 講習名 | 企画 | カリキュラム | 教材 | レビュー |
|---|---|---|---|---|
| AI基礎講座 | ✅ | ✅ | 🔄 | - |
| プロンプト実践 | ✅ | - | - | - |
```

判定基準:
- ✅ = 該当ファイルが存在（plan.md, curriculum.md, review.md）
- 🔄 = 一部のみ存在（materials/exercises の場合、カリキュラムのモジュール数と実ファイル数を比較）
- `-` = 未着手

`.training/` が存在しない場合は「この場所にはまだ講習がありません。`/training-plan "{講習名}"` で新しい講習を始めてください」と案内。

### パターン B: 特定講習の詳細（引数あり）

1. `.training/{講習名}/` 配下のファイルを走査
2. 以下を表示:

```
## {講習名} - 進捗状況

### フェーズ
- [x] 企画: .training/{講習名}/plan.md
- [x] カリキュラム: .training/{講習名}/curriculum.md
- [ ] 教材: .training/{講習名}/materials/ (2/5 モジュール完了)
- [ ] レビュー: 未実施

### 作成済みファイル
- plan.md (2025-04-02)
- curriculum.md (2025-04-02)
- materials/module1_intro.pptx (2025-04-02)
- materials/module2_basics.pptx (2025-04-02)
- exercises/exercise1_intro.md (2025-04-02)

### 次のステップ
`/training-materials "{講習名}" 3` でモジュール3の教材を作成
```

指定された講習が存在しない場合は「講習 '{講習名}' が見つかりません。`/training-status` で一覧を確認してください」と案内。
