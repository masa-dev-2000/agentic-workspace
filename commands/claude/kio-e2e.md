dev環境に対してE2Eテストを実行する。スモークテスト（基本動作確認）を必ず先に実行し、続いて対象PRに紐づくissueの仕様をもとにClaude自身がシナリオを生成してブラウザを操作しながら検証する。

引数: PR番号（省略時は直近のdevmergeで対象となったPR）

## プロジェクト設定の読み込み（最初に実行）

プロジェクトの `CLAUDE.md` の「KIO 設定」セクションから以下を読む:
- `dev_url`（必須）: テスト対象のdev環境URL
- `e2e_accounts`（任意）: E2Eテスト用アカウント（id/password）の一覧。記載がなければスモークテストの認証ステップでユーザーに確認する
- `smoke_test_steps`（任意）: プロジェクト独自のスモークテスト手順。未設定なら下記の汎用手順を使う

`dev_url` が未定義の場合は実行せずユーザーに確認する。

## テスト環境

- **dev URL**: 設定の `dev_url`
- **テスト用アカウント**: 設定の `e2e_accounts`（admin / viewer など、用途別）

## Phase 1: テストシナリオ生成

### 1-1. PR情報とissue仕様を取得
```bash
gh pr view <number> --json title,body,headRefName,closingIssuesReferences
```
PRタイトルとbodyから関連issue番号を抽出し、それぞれのissue仕様を取得:
```bash
gh issue view <N> --json title,body -q '"#\(.number): \(.title)\n\(.body)"'
```

### 1-2. テストシナリオを自動生成

issue仕様を読み、**「ユーザーが実際にブラウザで行う操作のステップ」**をClaude自身が考えて以下の形式でまとめる:

```
📋 テストシナリオ（PR #<番号>: <タイトル>）

【スモークテスト】（毎回必須）
（smoke_test_steps が設定されていればそれを使う。なければ汎用手順:）
1. dev_url にアクセスできるか
2. 認証が必要ならログインできるか
3. トップページまたは主要画面が表示されるか
4. （ログインした場合）ログアウトできるか

【issue固有テスト】
issue #<N>「<タイトル>」に対して:
1. <ブラウザ操作ステップ>
2. ...
期待結果: <何が起きるべきか>
```

シナリオをユーザーに提示して「このシナリオでテストします。開始してよいですか？」と確認する。

## Phase 2: スモークテスト実行

Claudeがブラウザを直接操作して上記スモーク手順を順に確認する。各ステップの結果を記録し、FAILがあれば即座にPhase 4（失敗処理）へ。

## Phase 3: issue固有テスト実行

Phase 1で生成した各シナリオを順番にブラウザ操作で実行する。

各テストケースの記録形式:
```
✅ PASS: <テスト名> - <確認できた内容>
❌ FAIL: <テスト名> - <期待: ...> <実際: ...>
⚠️ SKIP: <テスト名> - <スキップ理由>
```

## Phase 4: 結果処理

### 全PASS の場合

PRにテスト結果をコメントとして記録:
```bash
gh pr comment <number> --body "## ✅ E2Eテスト PASS

**実行日時**: $(date '+%Y-%m-%d %H:%M')
**環境**: dev (<dev_url>)

### スモークテスト
<各スモーク項目の結果>

### issue固有テスト
<各テスト結果>

🤖 /kio-e2eコマンドによる自動テスト"
```

完了メッセージ:
```
✅ E2Eテスト全PASS
PR #<N> は /kio-mainmerge で本番にリリースできます。
```

### FAILがある場合

1. テスト結果をPRにコメント記録（上記と同形式でFAIL項目を含める）

2. マージ済みPRを再オープン:
```bash
gh pr reopen <number> --comment "E2Eテストで失敗が検出されたため再オープンしました。上記のテスト結果を確認して修正してください。"
```

3. ユーザーへの報告:
```
❌ E2Eテスト FAIL
PR #<N> を再オープンしました。
失敗箇所: <FAIL項目一覧>

修正後に /kio-imple で再実装してPRを作り直してください。
```

## テスト完了サマリー

```
📊 E2Eテスト結果サマリー
PR #<N>: <タイトル>
スモークテスト: ✅ PASS (N/N)
issue固有テスト: ✅ PASS (N/N) または ❌ FAIL (M/N)
総合結果: PASS / FAIL
```
