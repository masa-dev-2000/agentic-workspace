---
description: いま使えるスキルを出所別（agentic-workspace / プラグイン / ランタイム組み込み）に一覧表示し、配線が正しいか検証する
---

いま自分が使えるスキルを、出所別に分類してチャットに表示する。

## 手順

1. 配線とワークスペーススキルの実体を取得する:

```bash
python -X utf8 C:/Users/masa/dev/agentic-workspace/scripts/list_skill_sources.py --names
```

2. 自分のシステムプロンプトに列挙されている利用可能なスキル名と、手順1の出力を突き合わせ、
   下記の表形式でチャットに出力する。推測で埋めず、突き合わせた結果だけを書く。

| 出所 | 判別方法 | 表示するもの |
|---|---|---|
| **agentic-workspace** | 手順1の WORKSPACE SKILLS に名前がある | スキル名を列挙 |
| **スラッシュコマンド** | 手順1の user slash commands に名前がある | 件数と代表例 |
| **プラグイン** | 名前が `プラグイン名:スキル名` 形式 | プラグインごとに列挙 |
| **ランタイム組み込み** | 上のどれにも該当しない | 件数と代表例 |

3. 配線の判定を最初の1行で述べる:
   - 手順1が `OK: all runtimes share this workspace` を出し、Claude Code / Codex / 中立パスが
     すべて `[SHARED]` なら「3ランタイムすべてが同一実体を共有」と明記する。
   - `[SEPARATE]` や `drift:` や `PROBLEMS` が出た場合は、**それを最優先で報告する**。
     どのランタイムがどこを読んでいるか、どのスキルが欠けているかを具体的に示す。

## 注意

- スクリプトの出力を検証なしに要約しない。`[SHARED]` と `[SEPARATE]` を取り違えないこと。
- ランタイム組み込みスキルの完全な一覧はファイルシステムからは取得できない。自分のシステム
  プロンプトの一覧から、workspace・コマンド・プラグインを除いた残りがそれに当たる。
- スキル名を全部並べると長くなる場合、agentic-workspace 由来だけは省略せず全件出す
  （これが「自分の資産が本当に読まれているか」を確認する目的そのものなので）。
