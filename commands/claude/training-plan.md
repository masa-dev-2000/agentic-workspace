講習の企画フェーズ。対象者・目的・制約・前提条件を整理して企画書を作成する。

引数: {講習名} - 講習のテーマや名称
例:
  /training-plan "AI基礎講座"
  /training-plan "プロンプトエンジニアリング実践"

## 設計思想

このコマンドは kiro のスペックドリブン開発と同じ思想で動作する。
- **カレントディレクトリ基準**: すべての成果物は現在の作業ディレクトリに作成
- **フォルダ自動構成**: 必要なディレクトリ構造を自動生成
- **フェーズ管理**: plan → curriculum → materials → review の順序で進行

## フォルダ構造（自動生成）

コマンド実行時、カレントディレクトリに以下を作成する:

```
.training/
└── {講習名}/
    ├── plan.md          ← このコマンドで作成
    ├── curriculum.md    ← /training-curriculum で作成
    ├── materials/       ← /training-materials で作成
    │   ├── slides.pptx
    │   └── handout.md
    ├── exercises/       ← /training-materials で作成
    │   └── exercises.md
    └── review.md        ← /training-review で作成
```

## 手順

### Step 1: 引数の確認

引数 `{講習名}` が指定されているか確認。未指定なら「どのような講習を企画しますか？講習名を教えてください」と聞く。

### Step 2: ヒアリング

以下の情報を AskUserQuestion で一括収集する（既に提供済みの項目はスキップ）:
- 対象者（誰向けの講習か）
- 目的・ゴール（受講後にどうなってほしいか）
- 想定時間（何時間 or 何日間）
- 前提知識（受講者に求める事前知識）
- 制約・特記事項（会場、人数、オンライン/オフラインなど）

### Step 3: ディレクトリ作成

カレントディレクトリに `.training/{講習名}/` ディレクトリを作成する。

```bash
mkdir -p ".training/{講習名}"
```

### Step 4: 企画書の作成

収集した情報をもとに `.training/{講習名}/plan.md` を作成:

```markdown
# {講習名} - 企画書

## 基本情報
| 項目 | 内容 |
|---|---|
| 講習名 | ... |
| 対象者 | ... |
| 目的 | ... |
| 想定時間 | ... |
| 前提知識 | ... |
| 形式 | ... |
| 作成日 | YYYY-MM-DD |

## 目標（ゴール）
受講後に達成すべき具体的な成果を箇条書きで記載。

## 制約・前提条件
- ...

## ステータス
- [x] 企画（plan）
- [ ] カリキュラム設計（curriculum）
- [ ] 教材作成（materials）
- [ ] レビュー（review）
```

### Step 5: 次のステップを案内

以下を表示:
> 企画書を作成しました: `.training/{講習名}/plan.md`
> 内容を確認してください。
> 次のステップ: `/training-curriculum "{講習名}"`
