GitHubイシューを即座に登録する。調査や深掘りはせず、ユーザーの言葉をそのまま記録する。

引数: 問題や要望の説明（自然言語）
例:
  /kio-issues ログイン時にエラーが出る
  /kio-issues カメラフィルタをサイドバーに移動してほしい

## ⚠️ 重要ルール
- **調査しない**: コードを読んだり、DBを確認したりしない
- **確認を挟まない**: ラベル選択・内容確認のステップを省略し、即座に作成する
- **深掘りしない**: 実装方針の検討は `/kio-deepen` で後から行う
- **ユーザーの言葉を尊重**: 勝手に内容を補完・編集しない

## 手順

### Step 1: タイトルとラベルを自動判定

ユーザーの引数から:
- タイトル（短く要約、40文字以内）
- ラベル（bugっぽければ bug、それ以外は enhancement）
を自動判定する。

### Step 2: 本文を生成

ユーザーの言葉をそのまま「## 概要」セクションに記載する。
スクリーンショットが添付されていた場合は参照を記載する。
実装方針は書かない（`/kio-deepen` で後から追記する）。

**本文テンプレート（共通）:**
```
## 概要
<ユーザーの説明をそのまま記載>

## スクリーンショット
（添付があれば参照、なければセクション自体を省略）
```

### Step 3: 即座に作成

確認なしで即座にIssueを作成する:

```bash
gh issue create \
  --title "<タイトル>" \
  --body "<本文>" \
  --label "<ラベル>"
```

### Step 4: 完了報告（1行で簡潔に）

```
✅ #<番号> <タイトル> を登録しました
```

複数のIssueを一度に登録する場合は、すべて作成してから一覧で報告する:
```
✅ Issue登録完了（N件）
| # | タイトル |
|---|---------|
| #100 | xxx |
| #101 | yyy |

深掘り: /kio-deepen 100, 101
```
