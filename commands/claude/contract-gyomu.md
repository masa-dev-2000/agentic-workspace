引数: なし（対話で進める）

  - `P_受.md` プロジェクト単価・受注者側有利
  - `P_発.md` プロジェクト単価・発注者側有利
  - `S_受.md` 成果物単価・受注者側有利
  - `S_発.md` 成果物単価・発注者側有利
  - `T_受.md` 時間単価・受注者側有利
  - `T_発.md` 時間単価・発注者側有利

## 全体ワークフロー

### Step 1: 単価モデルと立場を決める（AskUserQuestion を使用）

2問を1回の AskUserQuestion 呼び出しで取得する。

質問1「契約料金の単価モデルは？」
- プロジェクト単価（一括金額）
- 成果物単価（成果物の数量 × 単価）
- 時間単価（時間 × 単価）

質問2「どちらの立場を優先しますか？」
- 受注者（フリーランス・委託先）側を有利に
- 発注者（依頼主・委託元）側を有利に

回答から基礎テンプレを選択（例: 成果物 × 受注者 → `S_受.md`）。

### Step 2: カスタム条項の確認（AskUserQuestion, multiSelect=true）

「基礎テンプレに対して条項を差し替えますか？（複数選択可）」
- IP帰属を反転させる
- 損害賠償の上限を反転させる（上限あり ↔ なし）
- 再委託の扱いを反転させる（自由 ↔ 要承諾）
- 競業禁止条項を追加する（受注者側基礎で発注者寄りに）
- 委託者の無条件解除権（30日通知）を追加する
- なし（基礎テンプレをそのまま使う）

選択された項目は、後でユーザーに条文置換の対象範囲を確認した上で適用する。**v1では複雑な置換は避け、選択された項目だけを最終ドキュメントの末尾に「カスタマイズ予定の条項」セクションとして書き出し、ユーザーが手動で確認する運用とする。**（v2で自動置換に拡張予定）

### Step 3: 必須記入事項のヒアリング

選択した単価モデルに応じて、以下を1つのメッセージにまとめて尋ねる。ユーザーは1メッセージで一括回答する想定。**未指定の項目は ● のまま残しておき、ユーザーが後から記入できるようにする旨を伝える。**

**共通項目（全モデル）:**
1. 案件名（ファイル名に使う、例: 「ABC社_デザイン業務」）
2. 委託者: 住所 / 名称 / 代表者名
3. 受託者: 住所 / 名称 / 代表者名
4. 締結日（YYYY-MM-DD）
5. 業務内容（自由記述、別紙に記載）
6. 数量
7. 履行期日
8. 役務提供場所（成果物単価の場合は「給付場所」）
9. 管轄裁判所（例: 東京地方裁判所）

**単価モデル別の追加項目:**
- プロジェクト単価: 委託料総額（例: 「100万円」）
- 成果物単価: 成果物の名称 / 単位 / 単価（例: 「ロゴ1点あたり5万円」）／ 検品日数（例: 「5営業日」）
- 時間単価: 時間単価（例: 「8000円/時間」）／ 想定時間（任意）

### Step 4: テンプレートを読み込んで置換

選択した基礎テンプレ（`bases/X_X.md`）を Read で読み込み、以下のルールで置換する。

**置換ルール:**
- 冒頭「●（以下「委託者」という。）」→ 委託者名（住所＋名称）
- 冒頭「●（以下「受託者」という。）」→ 受託者名
- 冒頭「●年●月●日」（締結日）→ ユーザーの締結日
- 末尾「●年●月●日」（署名欄上）→ 同上
- 委託料 / 単価の `●` → ユーザー回答値（モデル別）
- 検品日数の `●営業日` → ユーザー回答値（成果物単価のみ）
- 「●●地方裁判所」→ 管轄裁判所
- 署名欄の【住所】【名称】【代表者名】→ ユーザー回答値（委託者・受託者それぞれ）
- 別紙の各空欄（目的 / 業務内容 / 数量 / 履行期日 / 役務提供場所 or 給付場所 / 成果物）→ ユーザー回答値

**未入力の項目は ● または空欄のまま残し、最終ドキュメントの冒頭にコメントで「未記入項目リスト」を書く。**

冒頭の `<!-- LABEL: ... -->` 行は削除する。

### Step 5: ファイル出力

カレントディレクトリに以下を作成:

1. `{案件名}_業務委託契約書.md` — 置換済みMarkdown
2. `{案件名}_業務委託契約書.docx` — Markdownを元にした .docx

.docx生成は `anthropic-skills:docx` スキル（docx-js経由）を使用する。Markdownを段落・見出しに変換して.docxを生成する。

**.docx生成の指針:**
- 「業務委託契約書」を見出し1
- 「（条項名）」がある段落を見出し3、その直下を本文
- 末尾の「別紙」セクションは表形式で表現
- A4縦、明朝系フォント、余白2cm程度

### Step 6: 完了報告

```
✅ 業務委託契約書を作成しました

種別: {単価モデル} × {立場}
出力:
- {cwd}/{案件名}_業務委託契約書.md
- {cwd}/{案件名}_業務委託契約書.docx

未記入項目: {未入力の ● が残った箇所のリスト}

カスタマイズ予定（手動確認）:
- {Step 2 で選んだ項目}
```

## 注意事項

- **法務レビュー必須**: 出力はテンプレートを機械的に組み合わせたものに過ぎず、本契約として使用する前に必ず法務担当者または弁護士のレビューを受けるよう、最終出力の冒頭に注意書きを入れる。
- **ファイル名にスラッシュ等の禁止文字を含めない**: 案件名に `/\:*?"<>|` が含まれる場合は `_` に置換する。
- **既存ファイルへの上書きは避ける**: 同名ファイルが存在する場合は連番（_v2, _v3）を付ける。
