# Meeting Playbook

## Recommended agenda

1. Conclusion and decision to make
2. Confirmation of current facts
3. Recommended first phase and alternatives
4. Scope, exclusions, evidence, and risks
5. Price, period, client participation, and cadence
6. Questions and objections
7. Decision and next actions

## Opening

Use a conclusion-led opening:

> 本日は、最初に取り組む範囲と進め方、費用、開始条件を決めることをゴールにしています。現時点では、まず〇〇を1か月単位で進め、△△は次段階に分ける案を推奨します。

## Objection handling

For “高い”:

1. ask what comparison or expected outcome informs the concern;
2. restate the bounded result and client burden;
3. reduce scope before reducing price;
4. never add work to defend the fee.

For “10万円の価値がない”:

1. identify the result that would make it valuable;
2. test whether that result fits the period and access conditions;
3. revise acceptance evidence or narrow the engagement;
4. stop if value cannot be demonstrated honestly.

For technical uncertainty:

1. state what is verified and unverified;
2. propose the smallest PoC with pass/fail evidence;
3. do not promise the full implementation before the PoC.

## Closing

A meeting is commercially closed only when one of these is true:

- approved: scope, price, start condition, and signer are agreed;
- conditional: remaining condition, owner, evidence, and deadline are agreed;
- declined: reason is recorded;
- deferred: decision date and required information are agreed.

“検討します” without owner and date is not a next step.
