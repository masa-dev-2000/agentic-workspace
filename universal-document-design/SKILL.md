# Universal Document Design

Use this skill with the document-creation skill. Put successful, low-effort completion ahead of decorative design.

## Design the reader's path

1. Identify the reader's immediate action, deadline, and proof of completion.
2. Put one primary action at the top of each page. Do not mix unrelated actions on the same page.
3. Use a short heading that begins with the action: `社内へ共有する`, `提出方法を選ぶ`, `提出前に確認する`.
4. Prefer two short pages over one dense page when the reader must act. Do not shrink type merely to fit content.

## Universal design baseline

- Use A4 portrait unless a different paper size is necessary.
- Use a Japanese system sans-serif font such as Meiryo or Yu Gothic; body text should normally be 10.5-12 pt, headings 14 pt or larger.
- Use left-aligned text, short lines, and 1.15-1.3 line spacing. Avoid justified text, narrow columns, and long uninterrupted paragraphs.
- Use high contrast: near-black body text on white, with dark blue or black headings. Use pale fills only as secondary support. Never make color the only signal for urgency or status.
- Pair each color with a label such as `期限`, `確認`, or `保存`.
- Use tables only for repeated action items or true comparisons. Keep checkbox targets and row height large enough to scan and mark.

## Action-guide pattern

- Page 1: the first required action, the exact files or inputs, and the record to keep.
- Page 2: submission or completion method, deadline, and final confirmation checklist.
- Lead with a labeled deadline box only when a deadline is material. State the consequence plainly.
- End each page with one clear transition sentence or next action.

## Content rules

- Replace abstract labels with observable actions, such as `Slackで2ファイルを共有する`.
- State file names, destinations, and proof to retain exactly.
- Put caveats after the action, not before it.
- Use one sentence per instruction where possible. Delete background that does not change the reader's decision.
- Make essential links descriptive and clickable; do not leave a raw URL as the only affordance.

## Verification gate

Before delivery, verify the final document in Word or through a renderer:

- The intended page count is correct.
- No page has a stranded heading, clipped table row, or dense wall of text.
- Every page answers: `何をするか`, `いつまでか`, `何を残すか`.
- The document remains usable when printed in grayscale and when read quickly at 100% zoom.
